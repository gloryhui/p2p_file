# ADR-011：原生候选包与外部验收边界

状态：T012 软件交付决策。固定 TASKS/PRODUCT ref `2041a38756b87ba7856dcd343624d98df2283c5a` 不改。最终 head、CI、归档校验和与审查/合并记录以 Issue #24 为准；没有完成外部 mandatory 项就不宣称 FINAL_ACCEPTANCE。

## 构建身份

build.rs 从真实 git HEAD、index/branch ref 和源文件变化读取完整 commit 与 clean/dirty 状态，写入编译时 metadata；没有凭空指定源码 SHA 的环境覆盖。无 git 的源码构建标 unknown。桌面 `--version` / `--build-info` / `--help` 在打开 GPUI 窗口前退出，未知/多余参数返回 2，不新增网络或文件业务入口。Windows 采用 GUI subsystem，metadata probe 使用真实重定向子进程而不是 shell 启动完成时间。

脚本只接受本机对应的三种原生架构；检查 ELF64 x86_64、PE x64、thin Mach-O arm64，拒绝 Intel/fat Mac 伪支持。候选要求源码 clean、二进制嵌入 head/target/state 完全一致，不能把旧构建或 dirty 预检标作 final。冻结 commit 后 HEAD/index 的变化触发重编译。不会更改核心 CLI 默认/协议、QUIC 参数、Session 读者、恢复或认证。

## 包与许可证

Linux tar.gz、Windows zip、Apple Silicon .app zip 使用优化构建；所有材料位于 checkout 外。附完整 build-info、实际大小/SHA256、逐文件 SHA256SUMS、native inspection、运行文档和许可证。归档 verify 独立解包到私有临时目录，拒绝路径穿越/Windows 路径/链接/重复项，检查完整文件集合、metadata、二进制、所有依赖源码哈希；预检不得作为正式候选验收。

依赖清单保守覆盖全部 Cargo resolved 包（包括 build/optional/其它 target），保留原 SPDX、authors/repository；不把清单叫当前 binary linked-only SBOM。原 LICENSE/NOTICE/COPYING/README 与完整上游 .crate 归档随包提供，归档 SHA256 对照 Cargo.lock。没有 license 根文件的 crate 仍保留完整源包和声明，不生成伪造版权。GPUI 改编输入控件保留 Apache 文本与修改归属。macOS 材料放进 Contents/Resources，Finder 仅安装 .app 时也保留。系统库由系统包管理器提供，不私自打包宿主库。

## 系统和签名

目标：Ubuntu24.04 x86_64 / Win10 22H2 + Win11 x64 / macOS13+ Apple Silicon。macOS release 构建指定 deployment target13.0，脚本检查实际 Mach-O load command，Info.plist minimum13.0。Hosted macos14 不算 macOS13 真机 smoke。

Linux ldd/readelf 实际记录；Windows直接读取 PE import RVA/descriptor，不因 dumpbin 缺失猜 DLL；实际 Get-AuthenticodeSignature 必须 NotSigned。macOS对完成 Resources 的 .app 作 ad-hoc codesign 并 verify，记录实际 Signature=adhoc，没有 Developer ID，不公证。ad-hoc 不是开发者签名。没有证书就不制造 credential/signing 成功证据。

CI 继续只有 PR/manual 触发；在每个原有 GPUI job 的 check/build/full library regressions 后生成并 verify release 候选，上传一个本机产物，windows-all 原验收不减。最终候选一套4job通过即可，不重复 push CI/rerun。Artifacts 保留14天；这是候选交付，不新建正式 Release 标签。实际结果和可下载链接存于 Issue #24。

## 证据与阻塞

原生 Linux X11/Xvfb/Openbox/Mesa 窗口、目录/重名/中文粘贴/DPI、512MiB同TaskID Pause/Continue 与 T011 跨平台真实进程 hard kill 是各自证据，不能互相替代。T012 的实际原生600秒会记录双方接收结果（bytes/receiver elapsed）、方向、MiB/s/Mbps、单调观察时间、二进制 SHA 和原始截图；UI 的两位 elapsed 是显示精度，不编造额外小数。

当前资源盘点：Linux执行机；SSH配置仅一个Linux云服务器；仓库 self-hosted runner为0。没有已配置可访问的物理 Win10/Win11、Apple Silicon、两台独立 NAT 客户端或签名凭证。软件完成后仍必须 FINAL_BLOCKED_EXTERNAL_VALIDATION，保留 Issue #24 open，并给出最小外部验收步骤。真实 Wayland/IME/物理DPI也保持未验证；不会把 Xvfb/剪贴板复制叫真实输入法。完整门禁得到真实设备后继续，不悄悄提高最低系统版本。

LC_BUILD_VERSION 的 minos 是部署最低版本，其内部 tool/version 是链接器版本，sdk 是SDK版本；首次候选混入tool version导致真实macOS打包失败。修复用逐行命令/字段解析，legacy LC_VERSION_MIN_MACOSX仍读其OS version；边界测试保留拒绝真实高于13.0最低版本，并覆盖SDK26/linker1167.5不被误判。失败head的CI保留但不能接受，新最终候选需完整exact-head门禁。
