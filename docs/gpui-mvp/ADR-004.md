# ADR-004：桌面能力、任务控制帧与测速所有权

状态：T005 协议决策。业务传输接入属于 T006–T009。

## 连接与兼容

现有 QUIC、Ed25519、TLS channel binding、预期 NodeId 校验全部完成后，较小 NodeId 打开第二条双向流。双方先交换 Hello(version=1, capabilities=15)，再交换 Ready；五秒内未完成、版本不匹配或缺少能力均关闭连接并向 UI 返回明确不兼容错误。PeerLifecycle 在此期间为 Negotiating，只有完成后才 Connected。能力位分别是任务协议、相对路径条目、暂停继续、测速所有权；它们声明本 ADR 的协议契约，当前阶段不宣称文件业务已经完成。

桌面帧使用独立命名空间：`[u32 little-endian payload length][P2PD 01][postcard Frame]`。Frame 为 request_id 与 Message。大小上限 4 MiB，读取长度头后、分配载荷前检查。拒绝尾随字节。旧 ControlMessage 的所有变体及其序号均不修改；桌面 magic 的首字节不可能被旧 CLI 当作有效变体。没有复用 TunnelOpen，也没有远程路径操作。

Message 变体顺序固定：Hello(0)、Ready(1)、Offer(2)、Resume(3)、Pause(4)、Paused(5)、ResumeTask(6)、Completed(7)、Error(8)、Speed(9)。后续只能追加或升级协议版本。握手 request_id 为零；业务请求非零。版本 1 不支持未知必需能力，允许忽略未知可选能力位。

## 任务身份与状态

TaskProtocol 固定绑定已经认证的 peer。调用者提供 Local/Remote 方向；不能把消息声明的身份当作认证身份。Offer 包含随机稳定 TaskId、可选目录 group_id、相对路径和文件清单或空目录条目。文件身份为现有 manifest root，目录身份为相对路径哈希。双方各自维护严格递增的每任务序号；Offer 必须从 1 开始。状态验证失败不修改绑定、序号或暂停状态。每个连接最多保留 128 个任务绑定，超限明确拒绝；后续队列不能绕过此资源上限。

Resume 只能由接收方发出，root 必须匹配，位图长度和末字节空余位严格校验。Pause 可由任一端提出；Paused 必须确认对方具体 pause_request_id，双方同时暂停需要两份确认。接收方已完成发布的 Completed 可以赢得暂停竞态，终态不回退。Completed 包含 TaskId、root 与回执版本 1。它只定义持久化回执的身份；接收端必须在持久发布和回执保存后发送，不能以收到最后一个 chunk 替代完成。该磁盘顺序由 T006/T007 接入和验证。

ResumeTask 只包含已授权 TaskId，没有远程路径字段。重连只能由本机持久任务库调用 restore 恢复已经授权的任务身份、方向和清单；未知 TaskId 被拒绝。重连序号归零，磁盘暂停/中断状态保留；不能自动扫描远程文件。Error 使用固定错误码，不透传包含绝对路径的异常文本。源文件的绝对路径和本机源版本只保存在 T003 本地任务记录中，绝不编码到网络。

## 输入约束

相对路径最多 4096 UTF-8 字节、64 层、每组件 255 字节；拒绝绝对路径、空组件、点/双点、反斜杠、控制字符、Windows 禁止字符、尾随空格/点、保留设备名（含 COM/LPT 的上标数字形式）。拒绝不能跨平台保真的名字，不静默改名。文件 basename 必须等于清单 file_name；现有清单校验继续执行，额外限制最多 65536 个 chunk、总长不超过 1 TiB。安全路径语法不能替代 T007 的根目录限制、符号链接检查与原子发布。

## 测速互斥契约

同一 peer 由较小 NodeId 唯一仲裁。双方开始请求都进入该仲裁者，已有文件或测速时返回 Busy。授权绑定 test_id、发起者、方向、时长及随机 128-bit stream_token。时长为 30 秒或 1–10 分钟整分钟。另一端只接受认证的较小 NodeId 授权，并检查本机文件活动冲突。上传流源为发起者，下载流源为另一端；完整 lease 和身份匹配才能 claim，且仅允许一次。取消/完成必须携带完整 lease，旧会话令牌不能结束复用相同 test_id 的新测速。活动测速禁止新文件开始。

T009 必须让连接只有一个 accept_uni 分发入口，以类型、完整 lease 与已认证连接归属分配流，不能给并发业务各自启动 accept_uni 消费者。此阶段只实现编码和仲裁状态机，没有测速数据、计时或统计执行。T006/T009 集成还必须在同一 session 所有者中串行提交文件/测速状态变化，并处理远端授权与本机文件状态冲突。

## 验证与证据边界

协议测试覆盖黄金编码、旧 CLI 判别值、非法清单/路径/位图/帧、错 peer/task、重复乱序、暂停竞态、恢复授权和测速令牌。真实 loopback QUIC 测试先完成身份握手，再由旧 ControlMessage decoder 拒绝桌面帧，验证客户端明确失败并关闭连接。既有多 peer 会话回归现在经过桌面协商。

本 ADR 不证明文件传输、磁盘恢复、目录发布、真实双 NAT、Windows 10/11 或 Apple Silicon 人工交互；这些属于后续独立任务。
