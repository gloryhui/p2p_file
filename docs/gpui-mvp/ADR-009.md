# ADR-009：原生产品界面与后台投影

状态：T010 实施决策；固定验收 ref `2041a38756b87ba7856dcd343624d98df2283c5a`，不改写 PRODUCT/TASKS。T011 负责完整故障 harness，T012 负责打包与物理平台/NAT 验收。

## UI 与领域边界

主界面展示信令、完整身份与复制、对端输入/认证状态、文件/目录队列、暂停/继续、发送并发、测速及接收目录。设置可展开，未配置时默认打开；没有硬编码服务器或假传输完成。被动接收端无需填发送者 ID，也能看到已认证连接和新任务。

窗口与文本输入仍使用 GPUI 原生控件及原有 EntityInputHandler，保留中文 UTF-16/组合范围/旧布局防护。选择器仍是平台 prompt_for_paths，Linux 使用系统 portal，不能用网页对话框替代。选择前捕获认证 peer 和 session epoch；返回后继续使用该绑定，旧会话返回的选择拒绝。文件命令交给既有 Session JoinSet/扫描池，UI 不执行扫描、哈希、网络或任务库磁盘操作。

TransferService 在 GPUI background executor 中提供轻量权威投影：只复制显示名称、task/group ID、固定 peer、方向、状态、安全诊断、已校验字节和速率，不复制 chunk manifest 或 stream token。每 250 ms 更新一次，独立于有界事件缓冲，收到任务和事件溢出不需要手动刷新。UI 渲染不取 TaskStore 锁。任务列表使用 uniform_list，仅渲染可见范围；目录有展开与真实部分失败统计。终态完成仍来自持久回执，Finalizing/100% 不等于完成；Paused 等非 Transferring 速率为零。

继续按钮绑定任务记录的 peer，不使用当前输入框。离线时先明确请求重连，并在本 session/generation 的 Connected 事件后提交 Continue；失败或会话重建清除等待请求。重复等待去重，无文件自动恢复。任务 ID 和收件根不因 UI 编辑而改变。

## 设置与测速

保存仍在 background executor 中完成验证与原子持久化，成功后才应用收件根和 1/2/3 并发。信令 host/port 未变时不重配置网络；保存并发或目录不会打断现有任务/测速。收件目录主界面展示已应用值，设置页展示待保存值，旧任务继续使用持久根。

测速沿用 T009 Session 命令与 lease 快照。授权等待与 Running 分开；收到结果/错误通知解除等待，取消只对实际活动 ID 生效。原始 bytes/elapsed 计算相邻采样差值的瞬时 MiB/s，平均 Mbps 使用接收方结果，单位分别为 2^20 与 10^6。迟滞无新样本时瞬时速率归零，取消/断开不能显示完成；缓存保留末次终态并限制为 MAX_PEERS 条，不驱逐活动测试。方向按本机与 lease owner 换算，接收端按钮无需预填发送者 ID。

## 键盘与验证边界

提供文本 Tab/Shift+Tab、完整 ID 复制、连接、文件/目录/收件目录选择、保存、并发/方向/时长选择、开始/取消测速和任务选择/暂停/继续快捷键。折叠设置和恢复启动时聚焦实际可见输入框；标点快捷键使用 GPUI 的字面 `,`。native smoke 发现隐藏输入焦点和错误 comma 键名后修复；不是仅靠静态声明认定可用。

Linux native smoke 使用 X11/Xvfb、Openbox、Mesa software Vulkan、真实 GPUI 进程、系统 GTK portal 和既有信令服务器：被动接收、中文文件、目录/空目录、实际 Pause/Continue 与 SHA256、测速/取消/保存并发不重连均有截图和内容证据。2x GPUI X11 缩放下验证最小逻辑 760×560 和中文/emoji 剪贴板往返。软件显示服务器的真实窗口不等于物理显示器；剪贴板与 EntityInputHandler 回归不等于真实中文 IME、Wayland、Windows/Apple Silicon 交互或双 NAT 验收，后者保留到 T012。
