# 任务筛选与历史清理（Issue #67）

传输列表增加搜索框，按空格分隔的关键词同时匹配文件名/相对路径、设备备注和设备 ID，大小写不敏感。
设备、方向和精确任务状态按钮按次序切换，可与搜索组合；重置恢复全部任务。筛选只改变列表投影，
不会更改队列、传输状态或通知观察。Tab 可进入搜索框。列表显示匹配任务数/全部任务数，组标题不计入任务数量。

有筛选时自动展开命中的目录子项。目录名称、整体状态、完成数、总大小仍来自完整目录，另显示命中数；
单个完成文件命中不会让有暂停/失败文件的目录变成「全部完成」。筛选隐藏选中任务时清除选择，
避免快捷键操作隐藏记录。通知点击清除筛选、恢复同一窗口并定位对应任务。

「清理完成历史」提示当前筛选内最多清理多少条，并要求在软件内确认。提交时固定当前匹配 ID 集合，
后台再次检查持久化状态；新增任务、未完成/失败/中断和仍活动的任务不会被清理。
目录组只有每个成员都已完成、非活动且均在选中集合中才整体清理，部分命中/未完成目录组全部保留。
取消不写入。一次原子快照保存成功后才更新内存、删除事件、速率缓存与列表；失败不会报告清理成功。

此功能只清理任务历史，不触碰已发送或接收文件、未完成任务的部分下载和恢复元数据；现有单文件删除操作独立。
清理后的完成历史及其中回执信息不能还原；用户文件仍保留在原位置。

验证覆盖组合过滤、大小写/中文名称、设备备注、折叠目录命中与完整目录统计、状态不被投影更改，
以及批量清理的完成状态/目录完整选择边界、原子写失败、事件顺序、重新打开任务库和原文件保留。
