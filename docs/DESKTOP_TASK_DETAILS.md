# 桌面任务详情与本机定位

任务行及目录组行的“详情”按钮打开主窗口中的只读面板。面板显示设备、方向、状态、大小和已确认字节、当前文件速度、数据预计剩余时间、耗时、尝试统计、分类错误及任务绑定的本机位置。目录组可分页查看全部保留子项（每页 10 项），进入单项详情后可返回目录组；统计和子项来自完整 TaskStore，不受主列表搜索、状态筛选及折叠影响。

发送目录统计来自本机保存的目录清单。接收协议逐项接纳目录和文件，不提供完整远端清单；接收组显示当前保留的全部已接纳子项，后续到达项继续更新。“已接纳子项均完成”只代表这些已知子项，不承诺远端没有后续项。清理历史后不恢复被清理子项，也不猜测原始数量。

## 速度、预计时间与耗时

- 大小和已确认字节复用任务清单及进度；完成任务以持久回执为准。目录自身大小为零，子文件各计一次。
- 仅正在传输的文件贡献有限、正数速度。暂停、中断、失败、排队、自动等待及验证收尾不沿用旧速度；缺少活动速度时显示未知。
- 预计时间为剩余文件数据除以当前有效文件速度，向上取整。它不包含排队等待、验证或收尾，也不预测未来网速；组中有暂停、失败、中断或自动等待项时显示未知。无速度、零剩余、非有限值和溢出均不生成估计。
- “创建至今或结果”使用任务创建时间到当前时间，所有保留子项完成或失败后冻结在其最后更新时间；包括等待、暂停及应用关闭期间。系统时间倒退而无法计算时显示未知。
- “本次活动用时”使用进程内单调时钟，累加实际占用任务的尝试，包含校验、入场及后台写入/收尾，直到旧活动及其未完成 I/O 释放。排队和两次尝试之间的暂停时间不累计。组内为子项活动时间之和，可大于墙钟时间。
- 尝试数只记录当前进程实际启动的活动，第一次不计为重新尝试；自动尝试每次最多计一次。重启后不伪造历史耗时和重试次数。统计最多保留 4096 项，优先淘汰结束活动；缺失数据明确显示本次运行暂无统计或已覆盖项数。此界面不触发重试、发送或协议请求。

## 本机位置

复制位置仅复制任务自身保存的本机路径。定位在后台重新检查记录和绑定，通过 GPUI 的原生文件管理器接口请求显示；不拼接 shell 命令，不访问远端，不删除或重新发送数据。

发送文件定位原源文件，发送目录或组定位保存的源目录。完成且提交回执的接收单项定位原绑定接收根下的最终文件/目录；未完成单项和接收目录组定位原接收根，不定位临时部分文件。之后修改默认接收目录不会改写历史任务位置。

检查复用现有 anchored/no-follow 文件系统入口，拒绝所检查根、相对路径组件或文件被替换为链接/reparse point、绑定不一致、路径缺失及记录已清理等情况。这里只确认位置仍符合绑定和普通文件/目录类型，不重新计算整个文件的内容散列；交给文件管理器之后仍受本机文件系统变化及系统权限影响。清理记录使选中的详情关闭，异步结果不会切换到另一项任务。

错误来自现有安全分类，不展示原始网络错误、令牌、密码或完整清单。界面只显示本机绑定位置及设备短 ID。

## 验证边界

自动测试覆盖单调耗时、暂停/重新尝试/自动尝试计数、重启后未知、统计上限、非法速度/ETA、部分失败的完整目录统计、任务与组 ID 区分、真实双端传输暂停恢复及回执、原接收根、目录与嵌套子项定位、清理历史后保留文件，以及 Unix 链接替换拒绝。四平台完整 GUI 回归、Clippy 和原生构建/打包验证代码接入；原生窗口排版、Finder/Explorer/Linux 文件管理器的实际打开行为仍需在相应桌面环境人工验收。
